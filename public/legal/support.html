Common issues · 常見問題

Symptom 症狀Fix 解法
Build mismatch / 版本不符Local: npm run relay-stop then npm run relay-ensure, reload pane. 重啟 relay 再重載 pane。
Relay down / Failed to fetchLocal: npm start. Hosted: check your network. 本機執行 npm start。
401 / key rejectedSettings → paste your own current Qwen key → Use key. 重新套用您的 key。
429 / rate limitWait and check quota/billing for your own API key. Do not use an Alibaba Token Plan key with this custom app unless Alibaba confirms permission. 稍候並查詢您自己的 API key 額度／收費；除非阿里雲確認允許，請勿在此自訂應用程式使用 Token Plan key。
PDF "no extractable text layer"Scanned PDF: add your key for vision transcription, or attach a text-based export. 掃描檔：加 key 視覺轉錄或改文字匯出。
Nothing sent / 沒有傳送Tick Share (consent gate). 勾選 Share。
Hosted key not remembered / key 無法記住Keep Remember ticked and press Save key · 儲存金鑰. The pane tries Office storage, then browser storage, and confirms which one worked. If it says session only, re-enter the key after reload or use the desktop local edition. 勾選 Remember 再按 Save key；增益集會嘗試 Office 儲存及瀏覽器儲存，並確認結果。若顯示只限本次使用，重載後須再輸入，或改用桌面本機版。

Requirements · 需求

  • Desktop Excel/Word with add-in sideload or store install; local mode needs Node.js 20+ on your PC. 桌面 Excel/Word；本機模式需 Node 20+。
  • Your own QwenCloud API key (BYO). 自備 Qwen key。
  • Optional local PDF tools: poppler (pdftotext/pdftoppm). 選配 poppler。
