Guide · 說明SOP

Modes 模式: Chat = read-only answers and whole-file review ("Please review the whole file"); Plan = proposal, writes only after Approve; Agent = steps with checks, destructive edits wait for a click. Direct on = safe edits apply immediately; Undo reverses them.
Share 分享: the Share toggle is the consent gate — off sends no workbook data. On sends the selection/active sheet (Chat) or the sheet inventory plus requested ranges (Agent), attachments, and locally saved skills/memory.
Key 金鑰: YOUR own Qwen key in both modes (BYO). Local: it stays on this PC. Hosted: Remember saves it in Office storage or this browser when available; each request sends it through the Worker to QwenCloud, and the Worker never stores it. 託管版記住金鑰時優先用 Office 儲存，否則用瀏覽器儲存；Worker 不會保存。
Local-only 本機限定: MCP (OneDrive), Skills, History, Memory and PDF/Word/Excel extraction need the local relay; the hosted pane hides them.
Data flow 資料流: workbook/attachment text goes pane → relay → QwenCloud only when you send; keys never enter the repo, the audit card or logs. Scanned PDFs are transcribed by rendering up to 12 pages and sending those images to QwenCloud with YOUR key (labelled in the attachment). Finance checks are computed by the pane, not the model.
Troubleshooting 疑難排解: every error now ends with "→" plus a bilingual fix. Common ones: build mismatch → restart relay (npm run relay-stop, npm run relay-ensure) + reload pane; relay down / Failed to fetch → npm start; 401 → re-apply your key in Settings; 429 → check your API quota; do not use Token Plan with this custom add-in; no text layer → add your key for vision transcription or attach a text export; Share off → tick Share.

MCPOneDrive

Read-only OneDrive search and preview. Press Connect to sign in with your personal Microsoft account in your browser. Each person uses their own account. A result is added to your next question only after you choose Review and add to chat.

Personal OneDriveNot connected
SkillsOneDrive

Copilot-format skills in your OneDrive folder (Copilot/Microsoft Excel/skills). The same Microsoft account receives them on another PC after OneDrive sync. With Share on, relevant skills are attached automatically; type @name to force one. Install from GitHub reads one SKILL.md. A public repo can omit the token. Remember keeps the token in this browser only. Tick Replace to update an existing skill. 技能在 OneDrive。另一部電腦用同一帳戶同步後可用。GitHub 只讀取一個 SKILL.md。公開 repo 可以不填 token。Remember 只把 token 留在這個瀏覽器。勾選 Replace 才更新已有技能。

Historysessions

Past conversations on this PC (local app data, like a CLI history). Resume restores the conversation and lets Agent continue from its checkpoint.

Memorynotes

Durable notes attached to every question while Share is on. Stored locally per Windows user — never in the repo or OneDrive.
