Guide · 說明SOP

Modes 模式: Chat = read-only answers and whole-file review ("Please review the whole file"); Plan = proposal, writes only after Approve; Agent = steps with checks, destructive edits wait for a click. Direct on = safe edits apply immediately; Undo reverses them.
Share 分享: the Share toggle is the consent gate — off sends no workbook data. On sends the selection/active sheet (Chat) or the sheet inventory plus requested ranges (Agent), attachments, and locally saved skills/memory.
Key 金鑰: YOUR own Qwen key in both modes (BYO). Local: it stays on this PC. Hosted: it stays in this browser and is sent per request; the Worker forwards it to QwenCloud and never stores it.
Local-only 本機限定: OneDrive search, Saved skills, History, Memory and PDF/XLSX extraction need the local relay; the hosted pane hides them.
Data flow 資料流: workbook/attachment text goes pane → relay → QwenCloud only when you send; keys never enter the repo, the audit card or logs. Scanned PDFs are transcribed by rendering up to 12 pages and sending those images to QwenCloud with YOUR key (labelled in the attachment). Finance checks are computed by the pane, not the model.
Troubleshooting 疑難排解: every error now ends with "→" plus a bilingual fix. Common ones: build mismatch → restart relay (npm run relay-stop, npm run relay-ensure) + reload pane; relay down / Failed to fetch → npm start; 401 → re-apply your key in Settings; 429 → wait / check Token Plan balance in console; no text layer → add your key for vision transcription or attach a text export; Share off → tick Share.
